Guías de estudio de chambapp

Una explicación profunda, fase por fase, de cada decisión técnica del proyecto: el qué, el cómo y sobre todo el por qué.

chambapp es un marketplace de changas (servicios) reconstruido como proyecto cloud-native: FastAPI + SQLAlchemy 2.0 + PostgreSQL en el backend, React 19 + TypeScript + Vite + Tailwind en el frontend, y despliegue en Cloud Run y GKE. Estas guías están pensadas para estudiar a fondo y para defender el proyecto en entrevistas.

Las cinco fases

FASE 1

Fundación del backend

SQLAlchemy 2.0 (estilo Mapped), modelos ORM y relaciones, config con pydantic-settings, engine/session, JWT + bcrypt, Docker base.
FASE 2

Backend de dominio

Schemas Pydantic v2, routers FastAPI, inyección de dependencias, flujo de autenticación, Alembic (migraciones) y tests con pytest.
FASE 3

Frontend React

Componentes y hooks, Context para auth, react-router, cliente fetch tipado, TypeScript de punta a punta y Tailwind v4.
FASE 4

Docker & Cloud Run

Imágenes Docker, Cloud Run, Cloud SQL, Secret Manager, Artifact Registry y CI/CD con Cloud Build + GitHub Actions.
FASE 5

Kubernetes / GKE

De Cloud Run a Kubernetes: Pods, Deployments, Services, Ingress, HPA, Secrets y Workload Identity. Con enfoque práctico y de entrevista.

Cómo usar estas guías

  • Cada página es independiente y se abre con doble clic (no necesita internet).
  • Los recuadros marcan el tipo de contenido: 🧠 concepto 💡 tip ⚠️ ojo 🎯 entrevista.
  • El bloque 🎯 entrevista simula preguntas típicas con su respuesta corta, para practicar.
